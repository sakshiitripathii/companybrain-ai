# CompanyBrain AI

## Project Overview
CompanyBrain AI is a graph-based company knowledge and recommendation system built using FalkorDB.

The project stores information about employees, skills, and projects and uses graph relationships to answer company-related questions.

## Technologies Used
- Python
- FalkorDB
- Graph Database
- Google Colab
- Cypher Query Language

## Key Features
- Stores employees and their roles
- Stores employee skills
- Connects employees with projects
- Queries relationships between employees, skills, and projects
- Provides knowledge-based answers using graph queries

## Example
The system can answer questions such as:

"Who knows Python and worked on the Sales Dashboard?"

- `companybrain_ai.ipynb` — Main Google Colab notebook
